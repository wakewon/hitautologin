HIT 自动登录 · Firefox 使用教程

仅在已确认的 HTTPS 统一认证表单和 WLAN 面板填写账号密码。学术网站可点击右下角“哈工大登录”，自动进入机构登录并选择本校。

安装本地开发版

  1. 在仓库目录执行 npm run build:firefox-dev，生成独立 ID 的 dist/firefox-dev。
  2. 在 Firefox 地址栏打开 about:debugging#/runtime/this-firefox。
  3. 点击“临时载入附加组件”，选择生成目录里的 manifest.json。
  4. 安装或重新载入后，刷新已打开的目标网页。Firefox 重启后需要再次临时载入。

不需要原作者账号。开发版与商店版设置独立，需要重新填写账号；测试时停用旧版及重复运行的同类油猴脚本，以免重复接管。

设置与一键登录

  • 点击扩展图标填写账号密码。开启“自动登录”后，统一认证页才自动提交；关闭时只填充。
  • “学术网站自动选校”独立控制机构选择。关闭后，仍可主动点击“哈工大登录”执行一次。
  • 隐藏悬浮按钮后，可在扩展弹出页点击“哈工大机构登录”，或使用网页右键菜单。
  • 已记住本校时可继续登录；延迟搜索/选择有限重试，并核对当前选中状态后提交。
  • 用户手动修改学校时脚本暂停。点击一键按钮可重新开始；人机验证请手动完成。
  • 弹出页可以查看/清空失败记录，最多保留 30 条站点、原因、时间，不保存完整 URL。

范围与更新

知网、ACS、Wiley、ScienceDirect、Springer、Cambridge、IEEE、Emerald、DDS、JoVE、SAGE/CARSI 等流程已登记。ASME 本次 CARSI 列表未提供哈工大，其他待验证项见仓库 docs/library-adapters.md。

学工子站、密码找回和 WebVPN 代理内容不会填写校园密码。浏览器内部页面、附加组件商店等受限页不注入脚本。更新代码后重新构建开发目录，在调试页点击“重新载入”，再刷新目标网页。

需要重启后保留的版本，可使用自己的 Mozilla 开发者账号为独立 ID 申请自分发签名。详见仓库 docs/firefox-dev-install.md。

HIT Auto Login · Firefox Help

Credentials are used only on verified HTTPS HIT CAS and WLAN forms. On supported academic sites, use “Sign in via HIT” to open institutional sign-in and select HIT.

Load the local development build

  1. Run npm run build:firefox-dev in the repository.
  2. Open about:debugging#/runtime/this-firefox in Firefox.
  3. Choose “Load Temporary Add-on” and select dist/firefox-dev/manifest.json.
  4. Refresh existing website tabs. Load the extension again after restarting Firefox.

No original developer account is needed. The development build has a separate ID and separate settings. Disable duplicate copies or matching userscripts during testing.

Settings and sign-in

  • Enter credentials in the extension popup. Auto Login controls submitting verified HIT forms.
  • Institution auto-selection is independent. An explicit one-click request still works when auto-selection is off.
  • The popup and context menu provide institutional sign-in even when the floating button is hidden.
  • Remembered HIT selections can continue. Delayed search/selection is retried within limits; the current selection is checked before continuing.
  • Manual institution input pauses automation. Complete human verification yourself; click the button to retry.
  • The popup can show and clear up to 30 failure records containing only host, reason and time.

Limits and updates

See docs/library-adapters.md for coverage and verification status. ASME did not list HIT in the checked CARSI list. Publisher subscriptions and personal-account requirements still apply.

Rebuild, reload from about:debugging, and refresh website tabs after code changes. Restricted browser pages cannot run content scripts. A persistent release/beta install requires a Mozilla-signed build; the separate development ID can be signed under your own account.
